# 🔐 Auth App (React + Redux + FreeAPI)

A simple authentication-based web application built using React.  
It includes user login, registration, and protected routes using Redux for state management and FreeAPI for backend services.

---

## 🛠️ Tech Stack

- React.js
- Redux Toolkit
- React Router DOM
- JavaScript (ES6+)
- FreeAPI (Authentication API)

---

## ✨ Features

- User Registration (Signup)
- User Login with authentication
- Protected Dashboard route
- Redux state management for auth flow
- API integration with FreeAPI
- Error handling for login/register
